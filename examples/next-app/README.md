# next-app example

This folder contains App Router snippets for integrating `@clemsrec/next`.

## Example routes

- `app/api/carbon/route.ts` for collection
- `app/api/chat/route.ts` for tracking AI usage in route handlers

See `CARBON_INTEGRATION.md` for environment flags and diagnostics notes.

These are code snippets for integration guidance and are intentionally minimal.
